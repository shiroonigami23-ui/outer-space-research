| Resource | What it contains | Link |
|---|---|---|
| NASA Exoplanet Archive | Every confirmed exoplanet with parameters | <https://exoplanetarchive.ipac.caltech.edu> |
| Gaia Archive | Positions, distances and motions of ~2 billion stars | <https://gea.esac.esa.int/archive/> |
| MAST | Hubble, JWST, TESS and Kepler data | <https://archive.stsci.edu> |
| NASA ADS | Every astronomy paper | <https://ui.adsabs.harvard.edu> |
| arXiv astro-ph | Free preprints | <https://arxiv.org/archive/astro-ph> |
| JPL Horizons | Positions of every solar system body | <https://ssd.jpl.nasa.gov/horizons/> |
| JPL Small-Body Database | Asteroids and comets | <https://ssd.jpl.nasa.gov/tools/sbdb_lookup.html> |
| Minor Planet Center | Asteroid discoveries | <https://minorplanetcenter.net> |
| GWOSC | LIGO/Virgo gravitational-wave data | <https://gwosc.org> |
| Planetary Data System | Mission data from NASA planetary missions | <https://pds.nasa.gov> |
| ISRO PRADAN / ISSDC | Chandrayaan, AstroSat and Aditya-L1 data | <https://pradan.issdc.gov.in> |
| NASA Space Weather (DONKI) | Flares, CMEs and storms | <https://kauai.ccmc.gsfc.nasa.gov/DONKI/> |
| Stellarium | Free planetarium software | <https://stellarium.org> |
| Zooniverse | Help classify galaxies and planets | <https://www.zooniverse.org> |
